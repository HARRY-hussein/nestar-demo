# Nestar Web — Prototype

Early prototype of the **Nestar** real-estate marketplace web client, used to plan routing and pages before the full client was built.

**Stack:** Next.js 16 (Pages Router) · React 19 · TypeScript

## Pages
| Route | Page |
|---|---|
| `/` | Home |
| `/property` | Property list |
| `/property/[productId]` | Property detail (dynamic route) |
| `/community` | Community board |

## Run
```bash
yarn install
yarn dev   # http://localhost:3000
```

Backend: [HARRY-hussein/nestar](https://github.com/HARRY-hussein/nestar)
